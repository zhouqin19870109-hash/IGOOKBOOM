# IGOOKBOOM

手機及周邊配件批發展示網站，使用繁體中文，支援手機與桌面版面。

## 功能

- 六款示範選品、分類篩選與即時搜尋
- 詢價清單、數量調整、移除商品與採購備註
- 下載 UTF-8 文字詢價單（不會傳送訂單或個人資料）

商品為示範資料，沒有承諾價格、庫存或認證。正式營運前需提供真實商品資料、商品圖片、聯絡方式及交易條款。目前沒有付款或後端訂單服務。清單只保留於當前頁面，重新整理後會清空。

## 開發

無第三方依賴，無需建置。於儲存庫目錄執行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

以瀏覽器開啟伺服器，檢查分類、搜尋、加入詢價、數量與文字檔下載。停止時按 Ctrl+C。

`index.html` 為頁面，`style.css` 為響應式樣式，`app.js` 包含商品及互動。可將三個檔案部署到支援靜態檔案的平台；目前未自動設定正式部署。
