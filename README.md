# iGo · OK BOOM — Wholesale demo v2

在原有 HTML / CSS / JavaScript 目录上升级，保留绿色视觉、分类筛选和 TXT 下载，不需要构建或第三方依赖。

## 已实现

- 西班牙语（默认）、简体中文、英语：商品、导航、提示、详情、复核及下载内容同步切换。
- 10大分类，10款演示商品，独立 SKU、型号、款式、演示欧元单价和起订量。
- 品牌／型号／名称／SKU 搜索，浏览器原生型号候选提示；忽略大小写、空格、连字符和重音，支持苹果／三星／红米中文品牌别名。
- 商品详情、示意图放大、型号和颜色选择；不同型号及颜色分别计入清单。
- 数量范围校验（商品演示起订量至9999整数）、移除、演示金额汇总及备注。
- 本机保存清单、语言和备注，刷新恢复；存储失败时显示提示；可清空清单及备注。
- 模拟复核、模拟完成、UTF-8 TXT下载；没有网络订单、付款或消息发送。
- 沿用响应式布局、键盘焦点样式，增加原生 dialog 弹窗、跳转目录入口及图片失败回退。

## 数据与图片边界

所有价格、起订量、规格和适配关系都是测试数据，不是供应商报价或库存承诺。税费、运费没有计算。不得把演示金额用于真实采购。

当前图片仍为明确标注的 CSS 示意图，**不是真实商品照片**。`catalog.js` 的 `image` 字段预留了 `assets/products/filename.webp`（也支持 png/jpg/jpeg）路径；收到经核实、获授权的自有产品照片后再替换。相对路径限制避免从第三方图片站加载跟踪内容；加载失败回退到示意图。欧规充电器也仅为演示规格，未验证功率、协议和认证。

`catalog.js` 管理商品和分类，`i18n.js` 集中维护三语文案，`app.js` 管理现有目录和清单交互。商品和用户备注通过 DOM `textContent` 渲染，不把其当作 HTML 执行。

清单只存于当前浏览器 localStorage（键 `igookboom-demo-v2`）。不要在备注中输入客户或个人资料。此版本没有跨设备同步、后台、账户、库存或真实订单功能。旧版无持久化数据，不存在需要迁移的旧购物清单。

## 本地运行与检查

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8000`。需要支持原生 `<dialog>`、Unicode正则及 localStorage 的现代浏览器。

```sh
node --check app.js
node --check catalog.js
node --check i18n.js
node --test tests/catalog.test.cjs
```

实际操作验收步骤和本次检查结果见 [QA.md](QA.md)。

## 发布边界

本次更新通过独立分支和 Pull Request 提供，未发布网站、未改仓库可见性、未开启真实订单。代码没有自动发布配置。仓库私有与网站访问保护需分别配置；在核实托管、域名及授权后单独处理。不要在仓库提交真实客户、成本、银行资料或密钥。
